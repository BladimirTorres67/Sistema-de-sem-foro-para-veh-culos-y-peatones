# Sistema de semáforo para vehículos y peatones

## Descripción
Este proyecto consiste en un sistema de semáforo automatizado que controla las señales para vehículos y peatones mediante una placa Arduino UNO.

## Objetivo
Simular el funcionamiento de un semáforo que permita organizar el paso de vehículos y peatones utilizando un pulsador.

## Componentes utilizados
- Arduino UNO
- LEDs rojos, amarillos y verdes
- Resistencias
- Pulsador
- Protoboard
- Cables jumper

## Funcionamiento
Al presionar el pulsador, el sistema cambia las luces del semáforo. Los vehículos reciben la señal roja y los peatones la verde durante el tiempo establecido. Después, la luz verde peatonal parpadea y el semáforo vuelve a su estado inicial.

## Programación
El sistema fue desarrollado utilizando código C++ en Arduino.
